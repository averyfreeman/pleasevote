---
title: Voter information flow
description: How PLEASE VOTE™ turns an address into useful election information.
---

1. Enter a residential address in the voter-information form.
2. The app requests election and voter data from the configured Civic Information API.
3. The results page presents the election day, contests, candidates or referenda, polling locations, hours, and official administration links.
4. Use the official links in the response for registration and jurisdiction-specific rules.

The interface keeps the lookup focused: address input, a loading state, a clear error state, and a structured results view.
